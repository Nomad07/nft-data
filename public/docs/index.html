Quick start for AI agents

NFT Data provides structured OpenSea NFT collection and market data for AI agents. A single paid POST request returns floor price, trading volume, sales activity, supply, ownership count, and creation date for any OpenSea collection.

Endpoint
POST https://www.nftdata.app/api/get-collection-data
Price
$0.002 per successful request

Requests require a compatible payment client. Two payment protocols are supported:

  • x402 v2 - send a signed PAYMENT-SIGNATURE header. See x402 payment details below.
  • MPP evm/charge - send an Authorization: Payment header. See MPP payment details below.

OpenAPI specification: https://www.nftdata.app/openapi.json

Agent integrations and usage examples: the x402scan server page provides additional integration instructions and usage examples for compatible agent clients and tools.

Endpoint

POST https://www.nftdata.app/api/get-collection-data

The endpoint requires a valid x402 payment on every request. Unauthenticated calls return 402 Payment Required with a PAYMENT-REQUIRED response header containing the x402 challenge terms. Resolve the challenge and retry with a PAYMENT-SIGNATURE request header containing the signed payment. A successful settlement returns a PAYMENT-RESPONSE header with the settlement result.

Payment: x402 v2

x402 on Base mainnet. Payment is 0.002 USDC per request, settled on Base (chain ID 8453). The server advertises payment terms in the PAYMENT-REQUIRED response header on a 402 response. Submit the signed payment in the PAYMENT-SIGNATURE request header on your next call. If the request succeeds, the server returns a PAYMENT-RESPONSE header with the settlement result. Payment verification is handled by the PayAI x402 facilitator.
Settlement timing. Payment settlement is attempted only after collection data has been retrieved successfully from OpenSea. Requests that fail input validation (400) or encounter an upstream data error (404, 429, 502) do not reach the settlement step.

Payment: MPP evm/charge

MPP evm/charge on Base mainnet. Payment is 0.002 USDC per request, settled on Base (chain ID 8453). MPP (Machine Payments Protocol) is a protocol for API-level stablecoin payments. The server uses the evm/charge method with Base mainnet USDC.
Settlement timing. As with x402, payment settlement is attempted only after collection data has been retrieved successfully. Requests that fail input validation or encounter an upstream data error do not reach the settlement step.
1. Unauthenticated request - server responds with 402 and a challenge
HTTP/1.1 402 Payment Required
WWW-Authenticate: Payment method="evm", intent="charge",
    realm="www.nftdata.app", request="<base64url-encoded challenge>"
2. Client resolves the challenge and retries with the credential
POST https://www.nftdata.app/api/get-collection-data
Content-Type: application/json
Authorization: Payment <mpp evm credential>

{
  "collection": "azuki"
}

The credential is a signed EIP-3009 token authorization bound to the challenge. Compatible MPP clients handle challenge resolution and credential construction automatically.

3. Server settles and returns the receipt
HTTP/1.1 200 OK
Content-Type: application/json
MPP-Receipt: <receipt token>

{ ... collection data ... }

The server also accepts the credential in a Payment-Authorization: Payment <credential> header when a forwarding proxy preserves the application Authorization header separately. MPP and x402 credentials are mutually exclusive per request - do not send both. For full protocol details, see the MPP evm/charge documentation and the MPP HTTP 402 protocol reference.

Request

Headers
Content-Type: application/json
PAYMENT-SIGNATURE: <x402 payment token>
Body parameters
Field Type Required Description
collection string required OpenSea collection slug. Lowercase alphanumeric, hyphens, and underscores only. The slug is the identifier visible in the collection's OpenSea URL. Example: azuki, milady, basedpunks.
Example request
POST https://www.nftdata.app/api/get-collection-data
Content-Type: application/json
PAYMENT-SIGNATURE: <x402 payment token>

{
  "collection": "azuki"
}

Response fields (200)

Field Type Description
name string Collection display name.
slug string Collection slug (matches the value you sent in the request).
contracts array NFT contract addresses and their chains. Each item has address and chain.
floor_price number Current floor price.
floor_price_currency string Currency symbol for the floor price. Not always ETH -- always read this field alongside floor_price to interpret the amount correctly. Examples from live collections: ETH, USDC, HYPE.
one_day_sales number Number of sales in the last 24 hours.
one_day_volume number Trading volume in the last 24 hours.
one_day_volume_currency string | null Currency symbol for 24-hour volume.
seven_day_sales number | null Number of sales in the last 7 days.
seven_day_volume number | null Trading volume in the last 7 days.
seven_day_volume_currency string | null Currency symbol for 7-day volume.
thirty_day_sales number | null Number of sales in the last 30 days.
thirty_day_volume number | null Trading volume in the last 30 days.
thirty_day_volume_currency string | null Currency symbol for 30-day volume.
total_sales number Total lifetime sales count.
total_volume number Total lifetime trading volume.
total_volume_currency string | null Currency symbol for total lifetime volume.
num_owners number Current number of unique owners.
total_supply number | null Total number of NFTs in the collection.
created_date string | null Collection creation date (ISO 8601 format).

Error responses

402 Payment Required. No valid payment was supplied. The response includes a PAYMENT-REQUIRED header with x402 challenge terms. Resolve the challenge and retry with a PAYMENT-SIGNATURE request header.
400 Bad Request. The collection field is missing, empty, or contains characters other than lowercase letters, digits, hyphens, and underscores. Body: {"error": "..."}
404 Not Found. No OpenSea collection exists with the given slug. Body: {"error": "Collection not found."}
405 Method Not Allowed. The endpoint only accepts POST requests. GET and other methods are rejected.
429 Rate Limit Exceeded. The upstream OpenSea API rate limit was reached. A Retry-After header indicates how many seconds to wait before retrying.
502 Bad Gateway. The upstream OpenSea API returned a server error or an authentication failure. Body: {"error": "The upstream OpenSea API returned an error. Please try again later."}
